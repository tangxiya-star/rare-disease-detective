# Source cases

Holly's collected source cases for the ten slots (PRD §3). Drop the original case reports, links, or PDFs here, one per slot, named by case number, e.g. `01_guitarist_drd.pdf` or `01_guitarist_drd.md`.

Wiki reviews each one and converts it into `cases/<nn>_<slug>/case.json` plus a held-out reference file. See [CLINICAL_LEAD_BRIEF.md](../../docs/CLINICAL_LEAD_BRIEF.md).

Only de-identified, reuse-permitted, or synthetic material. No PHI.
